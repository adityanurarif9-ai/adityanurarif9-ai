Tentang saya

Saya senang mengeksplorasi bagaimana teknologi dapat membantu aktivitas sehari-hari dan membuat pembelajaran lebih interaktif. Repositori saya mencakup aplikasi pencatatan keuangan, website responsif, serta game bertema matematika dan sejarah Indonesia.

- Aplikasi keuangan: mengembangkan SakuPintar untuk pengelolaan uang saku dan FlexKas untuk pencatatan kas tim.
- Pengembangan web: membangun antarmuka dengan React dan Vite, serta mengintegrasikan autentikasi dan database menggunakan Supabase.
- Game edukasi: menggabungkan cerita, tantangan, dan materi pembelajaran melalui game berbasis web dan GDevelop.
